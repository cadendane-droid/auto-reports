What this means

Sample sizes are tiny (3–4 active users/week) — read every number below as directional, not statistical.
Strongest signal

The same handful of active users are going much deeper into core data entry: contacts added (3→18) and sources submitted (3→19) both grew ~6x week over week, for a combined +517%. Once someone is in the product, they're using it heavily.

Biggest concern

AI query engagement is collapsing, not just stalling. Onboarding conversion from Source Captured to first AI Query fell from 33% (last week) to 0% (this week), and raw AI queries run dropped 83% (6→1) — even though Contact Added and Source Captured both still convert at 100%. The drop-off is isolated entirely to the query step.

  1. 1. Close the gap between "Source Captured" and "First AI Query" — this is now a 2-week trend, not a blip. Funnel conversion on this exact step fell 33% → 0% while AI Query Run volume fell 83% (6→1) in the same week that Contacts + Sources Added rose 517%. Add an in-product nudge ("Ask Almura about this person") that fires immediately after source_submitted completes, so the first AI query happens in the same session instead of becoming a separate step users skip entirely.
  2. 2. Prioritize onboarding the remaining ~6 invited users over new feature work. New users onboarded fell 67% week over week (3→1), and only 4 of the ~10 target users have been onboarded so far. With this few active users, every other metric in this report is too noisy to act on with confidence — getting more of the target cohort signed up and active is the highest-leverage move available right now, ahead of further product iteration.
