How to read this report These event pairs look similar but measure different things and are never added together or treated as the same funnel step:
  • person_added ≠ source_submitted — adding a contact vs. submitting a source for extraction
  • graph_opened ≠ $pageview on /network — an intentional graph-open action vs. any page load of that route
  • profile_viewed ≠ $pageview on /people/[id] — viewing a profile vs. any page load of that route
